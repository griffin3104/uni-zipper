# uni-zipper 画面仕様

> ステータス: ドラフト(ヒアリング中)。要件は [機能要件.md](機能要件.md) を参照。

## 1. 基本方針

- 画面は **1画面** とし、状態によって表示を切り替える(タブや画面遷移は使わない)。
- ウィンドウはサイズ変更可能。
  - 初期サイズは 480×400。
  - 最小サイズも 480×400 とする(これより小さくしない)。
- ダーク/ライトモードは、OSの設定に合わせる。
- 画面制御を単純にするため、入力欄は状態に応じて出し入れせず、**常に表示**する。

## 2. 画面の状態

| 状態 | 内容 |
|---|---|
| 初期状態 | ドロップエリアのみ |
| 圧縮モード | ファイル一覧、圧縮先OS、暗号方式、パスワード、保存ボタン |
| 解凍モード | Zip名(パスワード付きの表示)、解凍ボタン |
| 処理中 | プログレスバー、キャンセルボタン |
| 完了 | 完了メッセージを表示 → 閉じたら初期状態に戻る |

### 状態遷移

```
初期状態 ──(Zip 1つをドロップ)──────→ 解凍モード ──(解凍ボタン)──→ 処理中 ──→ 完了 ──→ 初期状態
   │                                      │                          │
   └─(それ以外をドロップ)→ 圧縮モード ──(保存ボタン)──→ 処理中 ──→ 完了 ──→ 初期状態
                              │                    ↑
                              └───(キャンセル/クリア)───┘ → 初期状態
```

- 「クリア」ボタンは、初期状態以外のどの状態でも押せる(処理中を除く)。押すと初期状態に戻る。
- 処理中は、キャンセルボタンで中断できる。中断後は初期状態に戻る。

## 3. 各状態の画面

### 3.1 初期状態

- ドロップエリア: 「ここにファイル・フォルダ・Zipをドラッグ&ドロップ」と表示する。

### 3.2 圧縮モード

表示する項目:

| 項目 | 内容 |
|---|---|
| ファイル一覧 | ドロップした名前を表示(フォルダの中身は表示しない)。Zipは他と色を変える。 |
| 削除ボタン | 一覧の各行に付ける。1件ずつ削除できる(ワークフォルダのコピーも削除)。 |
| 圧縮先OS | 「自動」「Windows」から選ぶ。初期値は「自動」。 |
| 暗号方式 | 「ZipCrypto」「AES-256」から選ぶ。初期値は「ZipCrypto」。 |
| パスワード | 入力欄を常に表示する。未入力ならパスワードなしで圧縮する。 |
| 保存ボタン | 押すと、後述の保存フローを開始する。 |
| クリアボタン | 初期状態に戻す。 |

- 圧縮モードでも、ドロップエリア(一覧の領域)にさらにドロップして追加できる。
- シンボリックリンク(フォルダの中に含まれるものも含む)をドロップした場合は、そのドロップ全体を拒否し、エラーダイアログで理由を表示する。一覧には何も追加しない。
- 同名のファイル・フォルダを追加したときは、確認ダイアログを表示する(上書き / リネーム / キャンセル)。
  - 「リネーム」を選んだ場合は、自動で連番を付ける(例: `file.txt` → `file_1.txt`、フォルダは `folder` → `folder_1`)。
- 一覧が空になった場合は、初期状態に戻る。

#### 保存フロー

1. 保存ボタンを押す。
2. パスワードが入力されている場合は、確認用の再入力ダイアログを表示する。
   - 一致しない場合はエラーを表示し、保存フローを中止する(入力内容は保持)。
3. 圧縮先OSが「Windows」の場合は、名前の書き方をエントリごとに自動で決める(確認ダイアログは出さない)。
   - Shift_JISに変換できる名前はShift_JISで保存し、変換できない文字を含む名前だけ、元のままUTF-8(フラグ付き)で保存する。文字の置き換えはしない。
   - ただし、波ダッシュ `〜` は全角チルダ `～` に置き換える。
   - 名前を変えたもの(`〜` の置き換え、連番)の一覧は、完了メッセージで通知する。
4. 保存先とファイル名を入力する保存ダイアログを表示する(初期位置はデスクトップ)。
   - 保存先に同名のZipがある場合は、上書き確認を表示する。
5. 処理中の状態に移る。

### 3.3 解凍モード

表示する項目:

| 項目 | 内容 |
|---|---|
| Zip名 | ドロップしたZipのファイル名を表示する。 |
| パスワード表示 | パスワード付きのZipの場合は、その旨がわかる表示(鍵アイコン+「パスワード付き」)を出す。ドロップ時に判定する。 |
| 解凍ボタン | 押すと解凍を開始する。 |
| クリアボタン | 初期状態に戻す。 |

- 解凍ボタンを押すまで、解凍は始めない。
- パスワード付きZipは、解凍ボタンを押したときに、パスワード入力ダイアログを表示する。
  - 間違えた場合は再入力を求める(3回まで。3回失敗したら中止し、解凍モードに戻る)。
- 文字コードの判定が曖昧な場合は、解凍ボタンを押したあとに読み比べプレビューのダイアログを表示する。
  - 「Shift_JISとして読んだ場合」「UTF-8として読んだ場合」を並べ、ユーザが選ぶ。
  - 曖昧でない場合は、プレビューを出さずにそのまま解凍する。

### 3.4 処理中

- プログレスバーを表示する(ファイル名は表示しない)。
- キャンセルボタンを表示する。押すと処理を中断し、書きかけのファイルを削除する。
- 処理中は、ドロップ・クリア・保存・解凍などの操作を受け付けない。

### 3.5 完了

- 完了メッセージを表示する。
- スキップしたファイルがある場合は、メッセージにスキップしたファイル名の一覧を表示する。
- 名前を変更したファイル(波ダッシュ `〜` の置き換え、同名の連番)がある場合は、変更前と変更後の名前の一覧も表示する。
- メッセージを閉じると、初期状態に自動で戻る。

## 4. ダイアログ一覧

| ダイアログ | 表示タイミング | 選択肢 |
|---|---|---|
| 同名ファイル確認 | 圧縮モードで同名を追加したとき | 上書き / リネーム / キャンセル |
| パスワード再入力 | 圧縮の保存ボタン押下時(パスワード入力あり) | OK / キャンセル |
| 保存先指定 | 圧縮の保存ボタン押下時 | OSの保存ダイアログ |
| 上書き確認 | 保存先に同名のZipがあるとき | 上書き / キャンセル |
| パスワード入力 | 解凍ボタン押下時(パスワード付きZip) | OK / キャンセル |
| 文字コード選択 | 解凍ボタン押下後(判定が曖昧なとき) | Shift_JIS / UTF-8 / キャンセル |
| 完了 | 処理完了時 | OK |
| エラー | 処理の失敗時、シンボリックリンクの拒否時 | OK |

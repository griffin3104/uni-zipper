# uni-zipper 機能要件

> ステータス: ドラフト(ヒアリング中)。未決事項は「未決事項」セクションを参照。

## 1. 対象範囲

| 項目 | 内容 |
|---|---|
| アプリ動作OS | Windows / macOS(Linuxは対象外) |
| 言語 | 日本語の文字化けのみ対象(中国語・韓国語は対象外) |
| UI言語 | 日本語のみ |
| 対応形式 | `.zip` のみ(7z, rar, tar.gz等は対象外) |
| 技術 | Tauri |

## 2. 基本動作

- ドラッグ&ドロップで、圧縮対象(ファイル・フォルダ)または解凍対象(Zip)を指定する。
- 圧縮か解凍かは拡張子で判断する。
  - **Zip 1つだけ**をドロップ → 解凍モード
  - それ以外 → 圧縮モード
    - 複数のZipを同時にドロップした場合も圧縮モード
    - Zipとそれ以外が混在している場合も圧縮モード
- 解凍モードになったら、他のファイルのドロップは受け付けない。
- 圧縮モードの一覧では、Zipファイルを他のファイルと色を変えて表示する。
- 「クリア」ボタンで画面を初期状態(起動直後)に戻す。

## 3. 圧縮

### 3.1 ワークフロー

1. ファイル・フォルダをドロップするたびに、アプリ専用の一時ディレクトリ(ワークフォルダ)へコピーする。
2. ドロップした名前を画面に一覧表示する(フォルダの中身までは表示しない)。
3. 「保存」ボタン押下時に、Zipの保存先とファイル名をユーザに入力させる。
   - 保存ダイアログの初期位置はデスクトップ。
4. ワークフォルダの内容を圧縮し、指定の場所に保存する。
5. 圧縮完了後、ワークフォルダは即削除する。

### 3.2 同名ファイルの扱い

ワークフォルダ内に同名のファイル・フォルダがある状態で追加された場合、確認ダイアログを表示する。

- 上書き
- リネーム
- キャンセル

### 3.3 ファイル名変換(圧縮先OS指定)

ユーザが次の中から選択する。

| 選択肢 | 想定 | 変換方針 |
|---|---|---|
| 自動 | Windows / Mac / Linux のどれでも開ける | UTF-8フラグあり、NFC正規化 |
| Windows | 古いWindows標準機能・Lhaplusなど | Shift_JIS(CP932)、NFC正規化 |

- 「Mac」の選択肢は設けない(「自動」と出力が同じになるため)。
- 「Windows」を選ぶと、Linuxで開いたときに文字化けする。LinuxへZipを持ち込む場合は「自動」を使う。
- NFD問題(濁点・半濁点の分離)に対処する。

### 3.4 除外ファイル

圧縮時に、次のようなOS由来の不要ファイルを自動で除外する。

- `.DS_Store`
- `__MACOSX`
- `Thumbs.db`
- `desktop.ini`

### 3.5 パスワード

- 圧縮時にパスワードを設定できる。未入力ならパスワードなしで圧縮する。
- 保存ボタン押下時に、確認用の再入力を求める。
- 暗号方式は、圧縮時にユーザが選択する。
  - ZipCrypto(初期値): Windows・macOSの標準機能で開ける。互換性重視。
  - AES-256: 強度重視。標準機能では開けず、7-ZipやKekaなどが必要。
- 解凍時は、このツールでZipCrypto・AES-256の両方を復号できること。
  - ※AES-256の解凍が実装上できない場合は、AES-256を選択肢から外す。実装時に確認する。

### 3.5.1 保存先の同名Zip

- 保存先に同名のZipがある場合は、上書き確認を表示する。

### 3.6 進捗・キャンセル

- 処理中はプログレスバーを表示する(ファイル名の表示は不要)。
- キャンセルボタンで処理を中断できる。
- 中断した場合は、書きかけのZipを削除する。ワークフォルダも削除する。

### 3.7 完了時

- 完了メッセージのみ表示する(フォルダは開かない)。
- メッセージを閉じたら、自動で初期状態に戻る。

## 4. 解凍

### 4.1 ワークフロー

1. Zipをドロップする。
2. 文字コードを判定し、ファイル名を変換する(アプリが動作しているOSに合わせて自動変換)。
3. 判定が曖昧な場合は、プレビューで確認させる。
   - ファイル名の先頭数件を、「Shift_JISとして読んだ場合」「UTF-8として読んだ場合」で並べて表示する。
   - ユーザが正しく読めるほうを選ぶ。
4. Zipと同じ場所に、フォルダを自動作成して展開する。
5. 処理中はプログレスバーを表示し、キャンセルボタンで中断できる。
   - 中断した場合は、作成途中の展開先フォルダを削除する。
6. 完了時は、完了メッセージのみ表示する(フォルダは開かない)。メッセージを閉じたら、自動で初期状態に戻る。

### 4.2 展開先

- 展開先はZipと同じ場所に固定する。
- Zipの中身の構造にかかわらず、常に自動でフォルダを作成し、その中に展開する。
- 同名のフォルダが既にある場合は、末尾に連番を付ける(例: `名前_1`、`名前_2`)。

### 4.3 除外ファイル

Zip内に次のファイルがあれば、展開しない。

- `.DS_Store`
- `__MACOSX`
- `Thumbs.db`
- `desktop.ini`

### 4.4 パスワード付きZip

- パスワード付きZipも対象とする。
- ドロップ時にパスワード付きかどうかを判定し、画面に表示する。
- パスワードの入力は、解凍ボタン押下時に求める。
- パスワードを間違えた場合は、再入力ダイアログを表示する。
- リトライは3回まで。3回失敗したら解凍を中止する。

## 5. エラー処理

- 圧縮・解凍が失敗した場合は、エラーメッセージを表示する。
  - ワークフォルダ、書きかけのZip、作成途中の展開先フォルダは削除する。
- 読み取れないファイル(権限なしなど)があった場合は、そのファイルだけスキップして処理を続ける。
  - 完了時に、スキップしたファイル名の一覧を表示する。
